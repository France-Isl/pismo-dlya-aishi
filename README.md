# Письмо, которое нашло тебя

Интерактивное романтическое письмо для Айши от Ислама.

- 24 тёплых письма
- анимированные котята, мишки и другие животные
- три встроенных нашида и возможность выбрать свой аудиофайл
- персонализация имён и обращения
- установка на телефон как приложение
